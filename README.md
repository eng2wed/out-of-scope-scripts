## How to use

1. Send the reply the same day. Silence often reads as a yes.
2. Lead with the value of the idea, then name the fee and the date together.
3. Offer a clear choice (quote, swap, park, or rush) so the client can decide without a call.
4. Get a written "approved" before you start the extra work.
5. Point at the original scope, not at the client: "outside what we agreed" beats "you keep adding things".
6. After they approve, lock it in with a [change order](https://scopeline-xi.vercel.app/change-order-template?utm_source=github&utm_medium=directory&utm_campaign=oos-scripts-01).
