# 3. Scope swap (same budget)

**When to use:** They want something new but the budget is fixed. Offer a clean swap of equal effort, or keep both with a quote.

**Subject (optional):** Fitting [new request] into [Project] — swap or add

```
Hi [Client],

We can fit [new request] into the current budget if we swap it for something already scoped. The closest match on effort is dropping [existing deliverable].

Options:
1. Swap [existing deliverable] for [new request] — same fee, delivery stays [date]
2. Keep both — add [price], new delivery date [date]

Which would you prefer? Once you pick, I'll confirm it in writing before I start.

[Your name]
```
