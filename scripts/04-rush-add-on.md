# 4. Rush add-on

**When to use:** They need something extra and they need it sooner than the calendar allows. Price both the work and the rush.

**Subject (optional):** Rush quote for [request] by [rush date]

```
Hi [Client],

I can take on [request]. It's outside the current scope, and hitting [rush date] means rearranging other work, so here's the rush quote:

- Scope: [what's included]
- Standard fee: [price]
- Rush fee: [rush amount] (to deliver by [rush date])
- Total: [total]

If the original delivery date of [normal date] is fine instead, we can skip the rush fee. Reply with which option you want and I'll lock it in before starting.

[Your name]
```
