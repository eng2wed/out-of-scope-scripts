# 1. New feature mid-project

**When to use:** The client loves the work so far and wants a feature that was never in the brief. Treat it as a change order, not a free add.

**Subject (optional):** Adding [Feature] to [Project] — quote + timeline

```
Hi [Client],

[Feature] is a strong idea and I can see why you want it in this release. It wasn't part of the agreed scope, so here's what adding it would look like:

- What's included: [short description of the new feature]
- Fee: [price]
- Timeline: adds [X days / weeks] (new delivery date: [date])

I'll keep the current scope on track while you decide. Reply "approved" and I'll send a short change order to lock it in.

[Your name]
```
